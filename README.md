# Company-Report-End To End-Power-Bi
📄 Report Pages Overview
📌 1. Summary Report

Purpose: High-level business performance overview

Key Insights:

Total Orders, Revenue & Profit KPIs

Orders by Category & Sub-Category

Orders by Continent (Map Visual)

Revenue vs Target tracking

Date range slicer for time-based analysis

📌 2. Product Report

Purpose: Product-level performance analysis

Key Insights:

Orders trend by Start of Week

Average & Adjusted Price comparison

Profit & Adjusted Profit analysis

Weekly profit trends

Return count monitoring

📌 3. Customer Report

Purpose: Customer behavior & segmentation

Key Insights:

Customer-wise Orders & Revenue

Orders by Gender

Orders by Occupation

Orders by Age Group

Orders by Income Level

🔧 Features & Functionality

Interactive slicers (Date, Category, Customer)

Drill-down and cross-filtering

KPI cards and donut visuals

Map-based geographical analysis

🛠 Tools & Skills Used

Power BI Desktop

Power Query (Data Cleaning)

DAX (Basic Measures & KPIs)

Data Visualization & Analysis

✅ Key Takeaway

This dashboard helps businesses:

Track performance quickly

Identify top products & customers

Understand customer demographics

Monitor revenue, profit, and targets

🎯 Use Case

Ideal for:

Business performance reviews

Sales & product analysis

Interview project for Data Analyst / BI roles
